Что ломается в проде и как защититься

Когда агент запущен и работает сам, проблемы неизбежны. Вот что идёт не так и как это чинить:

ПроблемаЗащита
Пустой / странный вход (спам, битая форма) Нода IF перед LLM: проверка, что текст не пустой и не короче N символов. Если вход невалидный — идём по ветке «ошибка».
Сбой API LLM (timeout, квота) Ветка ошибки после LLM-ноды: если упал — отправляем уведомление админу, а не тихо «роняем» весь workflow.
Некорректный JSON на выходе try/catch в ноде Code: если JSON.parse() упал — фоллбэк: «ответ не парсится, нужна ручная проверка».
«Тихий» сбой (агент просто не запускается) Раздел Executions в n8n — смотрите историю запусков: что отработало, что упало, почему.

Чек-лист «Готов к запуску»

  • ✅ Webhook URL рабочий и доступен снаружи
  • ✅ На 5–10 тестовых примерах все ответы корректны
  • ✅ Добавлена ветка обработки ошибок (проверка входа / catch)
  • ✅ Таблица для записи создана, поля соответствуют JSON-выводу
  • ✅ Уведомления приходят тому, кому нужно
🛠 Практическое задание

  1. Добавьте ветку обработки ошибок. Перед LLM-нодой — нода «IF»: проверка, что текст НЕ пустой. После LLM-ноды — «Error Trigger» с уведомлением админу. В ноде «Code» — try/catch для JSON.parse().

  2. Прогоните на 5–10 реальных примерах. Разные входы: нормальная заявка, спам, пустой запрос, длинный текст. Убедитесь, что ошибки не «роняют» workflow.

  3. Включите workflow (Active). Переключатель в правом верхнем углу редактора n8n: «Inactive» → «Active». Теперь агент слушает Webhook и обрабатывает события автоматически.

    [СКРИНШОТ: переключатель Active/Inactive в n8n]

  4. Зафиксируйте результат. Запишите для себя: сколько задач обработал, сколько времени экономит (можно прикинуть: раньше на 1 заявку уходило X минут, теперь — 0).

  5. Заполните мини-рефлексию. Ответьте (для себя):

    • Агент включён (Active) и обработал ≥1 реальную задачу?
    • Сколько времени экономит агент в день / неделю?
    • Применю ли я этот навык на практике в ближайшие 2 недели?
    • Оценка курса: 0–10 (NPS)
✅ Чек-поинт

Само-проверка Дня 5

  • ✅ Добавлена ветка обработки ошибок / невалидного входа
  • ✅ Workflow прогнан на 5–10 реальных примерах, ошибки не «роняют» агента
  • ✅ Workflow включён (Active)
  • ✅ Агент обработал ≥1 реальную задачу автоматически
  • ✅ Зафиксирована экономия времени (X часов / неделю)
Рубрика «выполнено хорошо»: Active + обработано 5+ задач, измерена экономия. Агент стабильно работает без сбоев минимум сутки. 🎉 Цель курса достигнута!
