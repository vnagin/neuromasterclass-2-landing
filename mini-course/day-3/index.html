День 3

Промпт, который работает

Спроектируете промпт и настроите JSON-вывод, чтобы агент стабильно классифицировал и извлекал поля.

⏱ 35–50 мин · Уровень: начинающий
🎯 Цель дня

Научить агента стабильно возвращать машинно-читаемый результат (JSON) — чтобы он не «придумывал» и не ошибался в формате.

📖 Теория

Анатомия рабочего промпта: 5 частей

Хороший промпт — это не «пожалуйста, обработай заявку». Это чёткая инструкция из пяти частей:

  1. Роль — кто ты для модели. «Ты — ассистент отдела продаж.»
  2. Задача — что нужно сделать. «Проанализируй текст обращения и верни структурированный результат.»
  3. Правила — ограничения. «Если данных нет — ставь null, не выдумывай. priority: one of ["high","medium","low"].»
  4. Формат — в каком виде вернуть. Жёсткий шаблон JSON.
  5. Пример — образец входа и правильного выхода. Модель «видит» паттерн и копирует его.

Зачем нужен структурированный вывод (JSON)

Если модель возвращает свободный текст («Заявка горячая, клиент Иван, хочет внедрить ИИ…») — вы не сможете автоматически разложить это по полям таблицы. JSON даёт гарантированную структуру: каждое поле в своём ключе.

Галлюцинации и как их снижать

«Галлюцинация» — когда модель выдумывает данные, которых нет во входящем тексте. Четыре способа защититься:

  • Рамки значений — enum для полей. «category: one of ["горячий","тёплый","спам","другое"]».
  • Пример в промпте — один хорошо подобранный пример снижает ошибки в разы.
  • Temperature ≈ 0–0.3 — параметр в настройках LLM-ноды. Делает ответы стабильнее, менее «творческими».
  • Явный запрет на выдумывание — «ставь null, если данных нет».
🛠 Практическое задание

  1. Перепишите промпт под JSON-вывод. Используйте шаблоны со страницы /mini-course/assets/prompts/. Скопируйте Шаблон 1 и подставьте в ноду LLM.

  2. Настройте поля: category («горячий»/«тёплый»/«спам»/«другое»), priority («high»/«medium»/«low»), client_name, summary, draft_reply.

  3. Прогоните на 3–5 разных входах. Придумайте примеры: горячая заявка, спам, неполное обращение. Проверьте, что на каждом JSON стабилен — все поля на месте, enum не «плывёт».

  4. Понизьте temperature до 0.2 в настройках LLM-ноды. Прогоните ещё раз. Убедитесь, что ответы стали стабильнее.

✅ Чек-поинт

Само-проверка Дня 3

  • ✅ Промпт переписан под JSON (5 частей: роль, задача, правила, формат, пример)
  • ✅ На 3+ разных входах модель стабильно возвращает корректный JSON
  • ✅ Все поля (category, priority, client_name, summary, draft_reply) заполняются без «плывущего» формата
Рубрика «выполнено хорошо»: стабильный JSON на 3+ разных входах, включая «сложные» (спам, неполное обращение). Ни одно поле не теряется, формат не ломается.

Своя задача: используйте Шаблон 2 со страницы /mini-course/assets/prompts/ — замените поля под свою задачу (например, для отзывов: sentiment, theme, needs_reply).
