🗺 Карта агента

Одностраничный шаблон: спланируйте триггер, логику и действие вашего AI-агента

📋 Чек-лист пригодности задачи

До заполнения карты проверьте задачу по трём критериям:

  • Задача повторяется регулярно (каждый день / каждую неделю)
  • На входе есть текст (письмо / заявка / сообщение / комментарий)
  • Есть понятный желаемый результат (что должно произойти в конце)

Если хотя бы на один вопрос ответ «нет» — выберите другую задачу или подумайте, можно ли её докрутить.

🗺 Три блока карты — заполните
БлокВопросВаш ответ
1. Триггер Что запускает агента?
(новое письмо / заявка с сайта / сообщение в TG / строка в таблице)		 ________
2. Что понимает Что агент должен извлечь/решить из входа?
(категория, приоритет, имя, суть запроса)		 ________
3. Что делает Какое действие на выходе?
(записать в таблицу, уведомить, прислать черновик ответа)		 ________
📌 Пример заполнения (анкерный кейс)
БлокОтвет
1. Триггер Новая заявка с сайта (Webhook)
2. Что понимает Категория (горячий/тёплый/спам), приоритет, имя клиента, контакт, суть запроса
3. Что делает Записать все поля в Google-таблицу + прислать владельцу черновик ответа в Telegram
