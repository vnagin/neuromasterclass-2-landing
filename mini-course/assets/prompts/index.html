📝 Шаблоны промптов

Готовые системные промпты с анатомией: роль → задача → правила → формат → пример. Копируйте и подставляйте в ноду LLM.

📌 Памятка: анатомия рабочего промпта

Каждый промпт состоит из 5 частей. Не пропускайте ни одной:

  1. Роль — кто вы для модели (ассистент, эксперт, система)
  2. Задача — что нужно сделать, одним предложением
  3. Правила — enum-значения, запрет на выдумывание, temperature
  4. Формат — жёсткий шаблон JSON с именами полей
  5. Пример — образец входа и правильный выход
📖 Памятка по снижению галлюцинаций
  • Чёткие рамки значений: enum для категорий, приоритетов («one of [\"high\",\"medium\",\"low\"]»).
  • Пример в промпте: один хороший пример снижает ошибки в разы.
  • Temperature ≈ 0–0.3: в параметрах LLM-ноды. Меньше «творчества», больше стабильности.
  • Явное правило: «Если данных нет — ставь null, не выдумывай.»
Шаблон 1 — классификация + извлечение полей (JSON)

Для анкерного кейса «обработка входящих заявок». Скопируйте и вставьте в System Message ноды LLM.

Роль: ты — ассистент отдела обработки входящих обращений. Задача: проанализируй текст обращения и верни структурированный результат. Правила: - Если данных нет — ставь null, не выдумывай. - priority: one of ["high","medium","low"]. - category: one of ["горячий","тёплый","спам","другое"]. Формат: верни ТОЛЬКО валидный JSON, без пояснений: {"category": "...", "priority": "...", "client_name": "...|null", "summary": "...", "draft_reply": "..."} Пример входа: "Здравствуйте, хочу внедрить ИИ в продажи, бюджет есть, звоните 555-12-34, Иван" Пример вывода: {"category":"горячий","priority":"high","client_name":"Иван","summary":"Запрос на внедрение ИИ в продажи, бюджет подтверждён","draft_reply":"Иван, здравствуйте! Спасибо за интерес к внедрению ИИ. Ваш запрос передан менеджеру — он свяжется сегодня. Для ускорения: какие процессы вы хотите автоматизировать в первую очередь?"} Текст обращения: {{ваш_вход}}

Как использовать

  1. Скопируйте текст выше в System Message ноды OpenAI / Anthropic LLM.
  2. В User Message подставьте {{ $json.text }} — это переменная из предыдущей ноды (Set / Webhook).
  3. В настройках LLM: выберите модель (GPT-4o-mini / Claude 3 Haiku), temperature = 0.2, Max Tokens = 500.
  4. Запустите тест и проверьте JSON-вывод.
Шаблон 2 — адаптируй под свою задачу

Тот же каркас (5 частей), поля замените под свою задачу. Например, для анализа отзывов: sentiment, theme, needs_reply.

Роль: ты — [кто ты для модели]. Задача: [что нужно сделать с текстом]. Правила: - Если данных нет — ставь null, не выдумывай. - [поле_1]: one of ["значение_1","значение_2","значение_3"]. Формат: верни ТОЛЬКО валидный JSON, без пояснений: {"поле_1": "...", "поле_2": "...", "поле_3": "..."} Пример входа: "[реалистичный пример входа]" Пример вывода: {"поле_1":"...","поле_2":"...","поле_3":"..."} Текст обращения: {{ваш_вход}}
💡 Пример адаптации: анализ отзывов

Роль: ты — ассистент отдела контроля качества.
Поля: sentiment (one of ["positive","neutral","negative","mixed"]), theme (основная тема), needs_reply (true/false), urgency (one of ["critical","normal","low"]), summary (краткое резюме).
