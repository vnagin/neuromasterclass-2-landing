Соберёте workflow из 3 нод и получите осмысленный ответ модели на своих данных.

🎯 Цель дня

Собрать минимальный workflow из трёх нод и получить первый ответ LLM на вашем реальном примере.

📖 Теория

Интерфейс n8n: нода, соединение, запуск

n8n-редактор состоит из «нод» (блоков). Каждая нода — это одно действие: триггер, операция с данными, вызов LLM, отправка уведомления. Вы соединяете ноды линиями — данные текут слева направо.

[СКРИНШОТ/SCREENCAST: интерфейс n8n — панель нод слева, пустой холст, кнопка «Test workflow»]

System prompt vs User prompt

Когда вы вызываете LLM-модель, вы отправляете ей промпт — текст инструкции. Есть два типа:

  • System prompt — роль и правила. «Ты — ассистент отдела продаж. Всегда отвечай вежливо и по делу.» Задаётся один раз в настройках ноды LLM.
  • User prompt — конкретное сообщение. Текст заявки, который пришёл от клиента. Приходит динамически из предыдущей ноды.

Как подключить LLM-ноду

В ноде «OpenAI» / «Anthropic» вы создаёте Credentials — вставляете API-ключ один раз, и он сохраняется. Затем пишете System prompt в поле «System Message», а в User Message вставляете переменную из предыдущей ноды (например, {{ $json.text }}).

🛠 Практическое задание

  1. Создайте новый workflow в n8n: кнопка «+» → «Workflow». Откроется чистый холст с одной нодой «When triggered by…».

  2. Добавьте ноду «Set» — она задаст входной текст. В поле «Values» → Name: text, Value: текст реальной заявки / письма для теста.

    [СКРИНШОТ: нода Set с заполненными полями]

  3. Добавьте ноду LLM (OpenAI «Message a Model» или Anthropic «Message a Model»). Создайте Credentials (API-ключ). В System Message напишите: Ты — ассистент отдела продаж. Проанализируй обращение клиента. В User Message подставьте {{ $json.text }}.

    [СКРИНШОТ: нода LLM с заполненным System/User Message]

  4. Запустите workflow — кнопка «Test workflow». Убедитесь, что модель вернула осмысленный ответ на ваш текст.

✅ Чек-поинт

Само-проверка Дня 2

  • ✅ Workflow из трёх нод собран (Manual Trigger → Set → LLM)
  • ✅ Workflow запускается без ошибок
  • ✅ Модель возвращает осмысленный ответ на ваш реальный пример
Рубрика «выполнено хорошо»: ответ осмыслен и релевантен именно вашей задаче, а не просто пересказывает входящий текст. Если модель ушла не туда — попробуйте уточнить System Message.
🔀 Адаптировать под себя

Новичок: используйте анкерный кейс — текст заявки с сайта (например, «Здравствуйте, интересует внедрение ИИ в поддержку, перезвоните на 8-999-...»).

Своя задача: подставьте реальный текст из вашей задачи: письмо клиента, отзыв, сообщение из чата.
