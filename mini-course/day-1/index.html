📖 Теория

Агент — это триггер + «мозг» (LLM) + действия

В отличие от чат-бота, который ждёт вопрос — агент действует сам. Он реагирует на событие (триггер), «понимает» неструктурированный текст с помощью LLM и выполняет конкретное действие.

Агент — не скрипт. Скрипт работает по жёстким правилам: «если в письме слово X → сделай Y». Агент способен осмысливать текст: понять, о чём клиент написал, даже если он сформулировал это нестандартно.

Примеры агентов в бизнесе

  • Обработка входящих заявок: заявка с сайта → классификация (горячий/тёплый/спам) → запись в CRM → черновик ответа менеджеру.
  • Сортировка почты: входящие на info@ → автоматическая маршрутизация: счёт → в бухгалтерию, жалоба → в поддержку, партнёрство → руководителю.
  • Классификация отзывов: новые отзывы на маркетплейсе → определение тональности → запись в таблицу + уведомление при негативе.
  • Автоответы на типовые вопросы: «как оформить возврат?» → агент сам находит информацию в базе знаний и отвечает.
  • Сбор коммерческих предложений: входящее КП → извлечение цены, сроков, условий → сравнение в таблице.

Из чего собираем

n8n — low-code оркестратор. Вы собираете workflow из готовых «нод» (блоков): триггер, LLM-модель, действие. Без кода, всё в облаке.

LLM API — «мозг» агента (OpenAI / Anthropic). Вы даёте модели промпт, она возвращает осмысленный результат.

Анкерный кейс курса

В течение этих 5 дней мы соберём агента обработки входящих заявок:

Агент ловит заявку → классифицирует → извлекает поля → черновик ответа → запись + уведомление

Этот же шаблон вы адаптируете под свою задачу.

🛠 Практическое задание

  1. Выпишите 3 рутинные задачи — что повторяется каждый день и отнимает время? (Обработка заявок, сортировка писем, ответы на повторяющиеся вопросы, проверка документов, сбор данных.)

  2. Выберите одну — проверьте её по чек-листу пригодности в «Карте агента» (ниже). Выберите задачу, которая проходит по всем трём критериям.

    Чек-лист пригодности
    Задача повторяется регулярно (каждый день / неделю).
    На входе есть текст (письмо / заявка / сообщение / комментарий).
    Есть понятный желаемый результат (что должно произойти в конце).

  3. Зарегистрируйте аккаунт n8n — n8n.io → «Start free» (cloud, free trial).

    [СКРИНШОТ: регистрация n8n — страница signup с кнопкой «Start free»]

    Получите API-ключ LLM — OpenAI (platform.openai.com/api-keys) или Anthropic Console. Ключ нужен будет завтра.

    [СКРИНШОТ: где взять API-ключ — страница API Keys в личном кабинете]

  4. Заполните «Карту агента» — три блока ниже. Продумайте для своей задачи: что будет триггером, что агент должен понять из текста, какое действие выполнит.
